Calculating Student Mark Statistics Using Arrays

Explore how a simple list of numbers transforms into powerful analytics like averages, highest scores, grading distributions, and pass/fail metrics.

The Real-World Scenario

Imagine a teacher grading an exam for a class of 30 students. At the end of the term, the school administration requires a complete statistical breakdown:

  • Class Average (Mean) score
  • Highest and Lowest marks achieved
  • Total number of passing vs. failing students
  • Sorted ranking list from top to bottom

// Raw Input Data (Scores)

const studentMarks = [85, 92, 78, 60, 45, 95, 88, 72, 90, 67];

// Computed Statistics Output

{

totalStudents: 10,

average: 77.4,

highest: 95,

lowest: 45,

passingCount: 8

}

Why are Arrays Necessary?

Without arrays, managing bulk academic data would be practically impossible.

1

Sequential Storage

Instead of creating 30 separate variables (mark1, mark2, mark3...), an array stores all marks continuously in a single organized collection.

2

Built-in Array Methods

JavaScript arrays come with powerful built-in functions like .reduce(), .filter(), and .sort() that make calculations instantaneous.

3

Scalability & Flexibility

Whether a class has 5 students or 500 students, array logic remains identical. You can dynamically add, remove, or update student scores easily.
